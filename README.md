# Improving-Renewable-Energy-Hosting-Capacity-in-LV-Distribution-feeders
This page has the various MBDs (Model Based Design) based on SIMULINK, in which all the required and important Simulink models related to Distribution electrical network are present. 
Also it contains the Stateflow logic of "Break-Before-Make" technique for effective Load transfer among R,Y,B Phases.
There are also real time consumer meter data analysis, that captures key important parameters like Phase voltage, Phase current , Power factor and frequency at different timestamps of a day.
